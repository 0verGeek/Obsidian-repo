## 1. 简介

按键扫描几乎是蓝桥杯嵌入式竞赛必考的考点，我们需要掌握长短按的程序编写，以防万一，我们还需要掌握按键双击。

实现按键扫描主要有两种方法，分别是轮询法和中断法。其中按键法或许会比轮询法更加节省软件资源，但同时对代码编写的严谨性也会更高，在多个模块共同参与的情况下，出现问题的可能性更高。为了确保在比赛中稳定发挥，这里更推荐使用轮询法。

> 实现按键扫描的方法多种多样，每种方法各有优缺点，可根据不同需求进行选择和改进。

## 2. 方案设计

### 分析需求：

- 短按、长按和双击各代表一种功能
- 在同一个按键上区别三种状态
- 各状态之间不能有重叠（例如：在进行双击时，不能在第一次按下时先响应单击功能）

### 设计思路：

首先分析三种状态之间的区别。长按与短按的区别在于按键按下时间，可以利用定时器的计时功能来区分。单击与双击之间的区别在于，一，加上按键计数来实现区分。

``` c
uint8_t key_timer = 0;
void SysTick_Handler(void)
{
  /* USER CODE BEGIN SysTick_IRQn 0 */
	key_timer++;	//每1ms计数器加一
	if(key_timer>9)
	{
		key_timer = 0;	//计数器到10时清零
		key_scan();	//每10ms执行一次按键扫描函数
	}
  /* USER CODE END SysTick_IRQn 0 */
    HAL_IncTick();
  /* USER CODE BEGIN SysTick_IRQn 1 */

  /* USER CODE END SysTick_IRQn 1 */
}
```
